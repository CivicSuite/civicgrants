CivicSuite / CivicGrants

Grant files that survive the audit.

CivicGrants v0.2.0 ships opportunity triage, eligibility factors, application outlines, compliance calendars, optional database-backed grant records, staff review queues, CivicRecords context packets, adversarial local mocks, audit-ready exports, and an accessible sample UI.

Recovery v0.2.0

What ships

  • Sample opportunity triage.
  • Eligibility-factor matching.
  • Application outline helper.
  • Compliance calendar helper.
  • Optional grant persistence with CIVICGRANTS_GRANT_DB_URL.
  • Staff queue routes protected by CIVICGRANTS_STAFF_API_KEY.
  • Review-required CivicRecords and grant-file context packets.
  • Adversarial local integration mocks.
  • Audit-ready export checklist.
  • Public sample UI at /civicgrants.

What does not ship

CivicGrants does not determine official eligibility, submit applications, accept awards, provide legal advice, call live LLMs, use live funder feeds, or replace the grant system of record.
