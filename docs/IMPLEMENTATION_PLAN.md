# CivicGrants Implementation Plan

CivicGrants v0.1.0 establishes a deterministic foundation: runtime shell, sample opportunity triage, eligibility-factor matching, application outline helper, compliance calendar helper, audit-ready export checklist, and public sample UI.

Later releases add local grant catalog configuration, live funder feeds, CivicRecords file links, staff review queues, submission workflow integrations, and production data governance.
